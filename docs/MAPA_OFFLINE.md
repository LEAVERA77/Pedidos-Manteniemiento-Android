# Mapa y ubicación sin conexión

La capa offline incluida es un esquema de Natural Earth 1:10m (dominio público): rutas principales, algunos cursos de agua y localidades de Entre Ríos y alrededores (selección aproximada: longitudes −61,4 a −57,2 y latitudes −34,0 a −29,4). Es orientativa, **no** tiene detalle de calles ni precisión suficiente para navegación. Fuera de esa zona no hay base offline. [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/). Datos de origen: `ne_10m_roads`, `ne_10m_rivers_lake_centerlines`, `ne_10m_populated_places`; se seleccionaron elementos cuyo rectángulo intersecta el área, se redondearon coordenadas y se eliminaron atributos no usados. Leaflet 1.9.4 se distribuye localmente con su licencia BSD en `vendor/leaflet-1.9.4/LICENSE`.

Con conexión se usa el mapa habitual; al pasar offline se cambia a la capa esquemática y vuelve a la base online al reconectar. No se precargan teselas OSM ni se pretende descargar una región: la [política del servidor de teselas](https://operations.osmfoundation.org/policies/tiles/) lo prohíbe para uso offline. El aviso indica la limitación de detalle y cobertura. El GPS puede funcionar sin datos, pero necesita permisos, ubicación activada y tiempo o cielo visible. El marcador indica si es una ubicación reciente, antigua o manual y muestra hora y precisión si están disponibles; registros antiguos sin origen se identifican como tales. No se debe usar como referencia de seguridad ni asumir que un punto antiguo es actual.

## Preparación y despliegue

1. Publicar los cambios del repositorio web en GitHub Pages. La APK carga esa web, no la copia completa de assets. Una APK anterior puede recibir los cambios con conexión, pero dependerá de la caché del WebView para recuperar los archivos offline.
2. Compilar, firmar y distribuir la APK 1.0.41 o posterior. Esta versión empaqueta Leaflet y los datos estáticos y los entrega localmente solo para las rutas exactas de Pages; no empaqueta ni sustituye la app web entera.
3. Abrir e iniciar sesión con conexión, entrar al mapa al menos una vez y esperar a que cargue, antes de salir al campo. La shell y sus módulos siguen dependiendo de la caché limitada del WebView, que Android puede borrar; ni una primera instalación offline ni una caché borrada están garantizadas. Conceder permiso de ubicación y probar el GPS.
4. Probar en el teléfono: activar modo avión sin cerrar la app, verificar aviso/capa y solicitar ubicación; luego reiniciar sin conexión y verificar si la shell quedó en caché. Comprobar zona sin cobertura, GPS desactivado, permisos denegados y retorno de la red. La capa no proporciona un mapa detallado guardado ni permite preparar regiones adicionales.

Al cambiar conectividad, Android ajusta el modo de caché del WebView y evita la recarga con URL variable al volver de segundo plano si no hay red. `LOAD_CACHE_ELSE_NETWORK` puede servir recursos obsoletos, como antes al iniciar sin red; la aplicación debe tratar datos operativos offline como potencialmente antiguos. No hay garantía de Internet real cuando Android indica una red disponible.
